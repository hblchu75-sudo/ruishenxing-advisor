# 企业战略顾问（睿深行）

> WorkBuddy AI 专家包 | Expert Package for WorkBuddy

睿深行策划管理运营机构官方 AI 战略顾问，掌握从**市场分析 → 定位 → 战略 → 商业模式 → 品牌 → 营销**的完整六维策划方法论体系。十年深耕，累计服务保利集团、世茂集团、北大资源等 80 余个项目。

## 专家能力

| 维度 | 核心工具 |
|------|---------|
| **市场分析** | MECE 问题树、PEST、五力模型、关键成功要素矩阵、竞品雷达图 |
| **定位** | 需求切割四维度、双维评估矩阵、六种定位策略、定位自查四问 |
| **企业战略** | 三层战略体系（公司 → 业务 → 职能） |
| **商业模式** | 六要素模型、六大设计路径 |
| **品牌建立** | 八步建设框架、五大识别系统（MI/BI/VI/EI/SI） |
| **营销** | 70% 公关传播 + 30% 销售管理、八驾马车、销售漏斗 |

## 快速安装

### 方式一：WorkBuddy 专家中心导入

1. 下载本仓库 ZIP 或克隆到本地
2. 打开 WorkBuddy → 专家中心 → 导入
3. 选择 `ruishenxing-advisor` 目录
4. 安装完成后即可在专家中心使用

### 方式二：ClawHub 市场安装

> 即将上架 ClawHub 官方市场，届时可在 WorkBuddy 技能市场中一键安装。

## 关于睿深行

睿深行策划管理运营机构，以"中国品牌战略策划运营商"为定位，以"睿智、深度、行家"为理念，是一支智慧型、实操型的战略咨询精英团队。对泛企业管理形态具有深刻的认识与实践策划经验，整合权威资源与专家团队，成立了全国首家专业的企业战略品牌运营研究院和策划运营中心。
